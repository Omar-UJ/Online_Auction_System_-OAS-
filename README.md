## Overview
**ACHARACH.COM** is an online auction system that allows users to participate in auctions from anywhere. The system is designed to improve transparency, efficiency, and accessibility for buyers and sellers, particularly in Ethiopia.

This project combines a **React JS frontend**, **.NET + Node.js backend APIs**, and **SQL Server database** to handle real-time bidding, user authentication, and auction management.

---

## Features
- Online bidding from home or office.
- Real-time updates for auction status.
- Secure authentication for users and auctioneers.
- Detailed item listings with images and descriptions.
- Automated bid announcements.
- Multi-auction support.
- User-friendly interface.
- Reduced paperwork, fully digital process.
